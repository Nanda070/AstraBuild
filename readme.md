## 📖 Описание

AstraBuild — мощный индустриальный плагин для PaperMC-серверов, добавляющий продвинутый функционал механизмов, энергии и логистики на сервер. Плагин изначально разработан для проекта **Astra SMP** и полностью переносит дух классических индустриальных модов на сервер без необходимости скачивать моды клиентам.

### Основные возможности

🔋 **Энергетическая Система (EU):**
- **МФСУ (Energy Storage):** Аккумулятор, хранящий до 10,000,000 EU.
- **Энергетические трубы:** Желтые стеклянные панели, передающие энергию от хранилищ и реакторов к другим механизмам по всей сети.

☢️ **Ядерная Энергетика:**
- **Ядерный Реактор:** Генерирует колоссальное количество EU, но выделяет много тепла.
- **Охладитель Реактора (Coolant Tank):** Собирает воду из соседних источников (или котлов) для охлаждения Реактора.
- **Система радиации и взрывов:** При перегреве реактор взрывается, заражая окружающую местность (чанки) смертельной радиацией.
- **Очиститель Радиации:** Одноразовый механизм (Маяк), мгновенно очищающий радиацию в радиусе 100 блоков.

⚙️ **Механизмы и Переработка:**
- **Центрифуга:** Перерабатывает ресурсы, требуя EU.
- **Генератор Материи (Mass Fabricator):** Требует огромное количество энергии (1,000,000 EU) для создания Универсальной Материи.
- **Апгрейды:** Каркасы для ускорения работы (Overclocker) или получения дополнительных эффектов (Удача, Шелковое Касание).

⛏️ **Логистика и Автоматизация:**
- **Карьер (Quarry):** Автоматически добывает ресурсы в указанной области.
- **Логистические Трубы:** Светло-синие стеклянные панели для транспортировки добытых ресурсов.
- **Коннекторы (Connector Insert/Extract):** Блоки (выбрасыватели) для соединения сундуков с сетью логистических труб.

🛰️ **Орбитальные Удары:**
- **Терминал Спутника:** Заряжается энергией и ресурсами.
- **Орбитальный Пульт:** Позволяет запросить мощный разрушительный лазерный удар из космоса по координатам.

⚡ **Нано-Броня и Экипировка:**
- **Нано-Меч, Нано-Грудник, Нано-Джетпак и Химзащита.**
- Предметы заряжаются в интерфейсе МФСУ (50 EU в тик) и расходуют энергию при использовании.

> Требует установленного плагина [AstraSMP](https://github.com/Nanda070/AstraBuild) для некоторых интеграций.

## Установка

1. Скачайте последний .jar релиз.
2. Поместите в папку plugins/.
3. Перезагрузите сервер.

cd AstraBuild
./gradlew build
